## Notes: answerability classifier (2026-11-18)

**Test split (180 questions).** The main model (logistic regression, C = 0.1) reaches
90.6% accuracy; unanswerable precision 90.1%, recall 91.1%.

**Human held-out set (30 questions).** The same model drops to 66.7% (10 errors).
Logistic regression trained the same way without `n_words` scores 83.3% (5 errors), while
its test-split accuracy barely changes (90.0%).

- The main model's errors follow question length: 7 short answerable questions
  ("avg review score?", "kharif vs rabi total area") were refused, and 3 long, chatty
  unanswerable questions were accepted (P(answerable) 0.51 to 0.79). In our authored sets,
  unanswerable questions were written shorter (about 7 vs 10 words), so `n_words` learned
  a writing-style shortcut that the test split shares but real-style questions do not.
- Without `n_words`, the remaining errors are (a) three short Hinglish answerable
  questions about derived metrics ("kohli ne total kitne sixes mare", "bumrah ki overall
  economy", "verstappen ke ... podiums"): `schema_overlap` is 0 because sixes, economy
  and podiums are computed, not column names, and lowercase names are not counted as
  entities; (b) two `missing_column` questions (female customers, farmers' earnings)
  whose words partly match real columns.
- **Caveat:** 30 questions is small (one question = 3.3 points), and the held-out
  questions were AI-drafted and human-edited, some paraphrasing training questions. The
  direction of the `n_words` result is clear; its size is uncertain.
- **Decision for the author:** the main model currently keeps `n_words` (decision of
  2026-11-17). This evidence argues for dropping it from the deployed model; the choice
  is recorded in `docs/notes/handoff.md`.
