# Answerability gate experiment

Generated by `scripts/eval_gate.py`. Gate = deployed classifier (XGBoost, no `n_words`),
threshold 0.5, nothing tuned. Pipeline = validated mode, qwen2.5-coder:7b, temperature 0.
Answerable questions: correct if not refused and the answer matches the gold answer.
Unanswerable questions: correct if no answer is returned (gate refusal or pipeline failure).
The held-out set was used once before (to drop `n_words`), so its numbers are optimistic.

## Test split (180 questions: 90 answerable, 90 unanswerable)

| | Without gate | With gate |
|---|---|---|
| **End-to-end accuracy (strict)** | 28.9% | 57.8% |
| End-to-end accuracy (relaxed) | 36.1% | 64.4% |
| Answerable answered correctly (strict) | 33.3% | 26.7% |
| Unanswerable with no answer returned | 24.4% | 88.9% |
| Unanswerable that got an (invented) answer | 68 | 10 |

- Gate: correct refusals 79 / 90 unanswerable; false refusals 12 / 90 answerable (6 of them the pipeline would have answered correctly).
- Without the gate, 22 unanswerable questions produced no answer only because the pipeline failed (validation or execution error), not because anything recognised them.
- McNemar (strict, exact): gate only right 58, no gate only right 6, p = 0.0000.
